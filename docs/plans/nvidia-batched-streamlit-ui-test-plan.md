## Affected Pages/Routes

- `http://127.0.0.1:<streamlit-port>` — `python main.py`로 열리는 단일 분석 UI와 네 단계 결과 화면

## Key Interactions to Verify

- 로컬 경로를 선택하고 분석을 시작하면 Semgrep, 에이전트 분석, 정탐/미탐 검증, 최종 보고서 순서로 갱신된다.
- ZIP 프로젝트와 복수 소스 파일 업로드가 동일 파이프라인을 사용한다.
- 분석 중 입력과 시작 버튼이 비활성화되고 새 세션의 중복 실행이 거부된다.
- 완료 후 TP/FP/unknown/error/skipped 결과와 개선안을 필터링해 볼 수 있다.
- PDF/HTML, XLSX, JSON 보고서를 다운로드할 수 있다.

## Edge Cases

- Semgrep 미설치·실패, 발견 0건, NVIDIA 키 없음·인증 실패
- 일부 배치 실패, schema/ID 오류, 429·context 오류, 호출 예산 소진
- 검증 일부 실패와 보고서 생성 실패
- 악성 ZIP 경로, symlink·특수 파일, 중첩 ZIP, canonical 경로 충돌, Windows 예약명
- 업로드 파일 수·개별 크기·총 크기·압축률 초과와 모든 성공·실패 cleanup
- Streamlit rerun, 새로고침, 새 탭, 중복 클릭, 이전 결과 뒤 새 실행

## Critical Paths

- `python main.py` → Streamlit 자식 1회 실행 → 로컬 경로 분석 → 네 단계 완료 → 보고서 다운로드
- ZIP 업로드 → 안전한 추출 → 분석 → artifact bytes 보존 → 임시 작업공간 삭제
- 다중 항목 → deterministic pack → NVIDIA 분석 1회/검증 1회 → ID 재매핑 → TP/FP 표시
- 단계 중간 실패 → 부분 snapshot 보존 → 명확한 사용자 오류 → coordinator 해제 → 다음 실행 성공
